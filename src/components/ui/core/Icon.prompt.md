Renders one Lucide glyph. Requires `<script src="https://unpkg.com/lucide@latest/dist/umd/lucide.min.js">` on the page.

```jsx
<Icon name="arrow-right" size={20} strokeWidth={2} />
```

Default stroke weight is 2px at 20px — matches the even, rounded stroke of the LyRise mark. Lucide is a flagged substitution for a brand icon set that was not supplied.
